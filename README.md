# Docker Image Gallery

A full-stack Dockerized image gallery application with persistent image uploads, dynamic gallery rendering, modern dark-themed UI, and multi-container architecture using Docker Compose.

---

## Features

- Upload images
- Delete images
- Persistent Docker volume storage
- Dynamic image gallery
- Image zoom modal
- Hover-based delete button
- Responsive dark-themed UI
- Dockerized frontend and backend
- Multi-container setup using Docker Compose

---

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Nginx

### Backend
- Node.js
- Express.js
- Multer

### DevOps / Deployment
- Docker
- Docker Compose

---

## Project Architecture

Browser
↓
Frontend Container (Nginx)
↓
Backend Container (Node.js + Express)
↓
Docker Volume Storage
